Two-agent paper trading system for US stocks

The Analyst Agent picks what to trade and in which direction. The Trader Agent decides when and how, using the backtested ORB rulebook. The AI explains and scores, while plain code places every order and enforces every limit. The same Trader code runs live and in backtests.

Every LLM answer must fit a fixed schema. If a call fails, the module falls back to its code score and trading continues.

Trader rulebook in one place Section 5A

  • Entry: stop order at the first 5-min candle's high (green candle, long) or low (red candle, short)
  • Gate: stock in play (RVOL ≥ 1.0, top 20) and on the right side of the daily 200 EMA
  • Stop: 10% of 14-day ATR from entry
  • Exit: no target; close at 15:55
  • Backtest: +0.13R per trade, profit factor 1.24, 650 trades over 2 years; random stocks lose
